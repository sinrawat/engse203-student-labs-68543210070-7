## 2. รายการการสาธิตระบบครบวงจร (Full-Stack Demonstration Checklist)

- [x] **การทำงาน 3 ชั้นสมบูรณ์:** เปิดการทำงานพร้อมกันทั้ง React (Frontend), Express API และ SQLite Database
- [x] **การดึงข้อมูลคำร้อง:** หน้ารายการคำร้องบนหน้าเว็บสามารถดึงข้อมูลจากตาราง `requests` ในฐานข้อมูล `campus.db` ได้ถูกต้อง
- [x] **การสร้างคำร้องใหม่:** ส่งแบบฟอร์มคำร้องจากหน้าเว็บ สามารถบันทึกข้อมูลลงฐานข้อมูลจริง และได้รหัส REQ ใหม่ตามลำดับ
- [x] **การเปลี่ยนสถานะและการลบคำร้อง:** ทดสอบการเปลี่ยนสถานะคำร้องเป็น `in-progress` และ `completed` พร้อมการลบคำร้อง
- [x] **การตรวจสอบสถานะระบบ (/api/health):** เรียกใช้งาน Endpoint แล้วคืนสถานะ HTTP 200 พร้อมแสดง uptime และการเชื่อมต่อฐานข้อมูล
- [x] **ความคงทนของข้อมูล (Data Persistence):** สั่งปิด API Server (Ctrl+C) แล้วเปิดใหม่ ข้อมูลคำร้องที่บันทึกไว้ยังคงอยู่ครบถ้วน ไม่สูญหาย
- [x] **การรันโหมด Production (Single Port):** ทดสอบการรันคำสั่ง `npm run build` และเริ่มต้นเซิร์ฟเวอร์ด้วย `npm start` สามารถเปิดหน้าเว็บและเรียก API ได้ครบถ้วนผ่านพอร์ตเดียว
